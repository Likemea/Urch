Urch is an AI Discord Bot written in Python 3.9.13 and built on discordpy 2.3.2. It aims to provide a mixed variety of utility and entertainment commands and functions.
It currently runs on a minimal, free-tier e2-micro Google Cloud Debian 12 VM Instance. It lacks GitHub integration or workflows, requiring careful, manual drag-and-drop and testing. The Urch process is managed by PM2.
