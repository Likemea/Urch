Urch is an async AI Discord Bot written in Python 3.11.2 and built on discordpy 2.6.4. It aims to provide a mixed variety of utility and entertainment commands and functions.
It currently runs on a minimal, free-tier e2-micro Google Cloud Debian 12 VM Instance. It lacks GitHub integration or workflows. The Urch process is managed by PM2.
